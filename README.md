# Weather-App-Tkinter
Built a weather app using Python Tkinter library

Learnt it from Youtube video : 
Python Project - Make a Weather App in Python Tkinter GUI (https://www.youtube.com/watch?v=FeR0wnXlp9c)

Key Features :
1. Displays weather, humidity, wind speed and temperature of the given city across the earth.
2. Weather icon enhances the results along with the details.
3. GUI used is Tkinter, a standard, built-in library which comes pre-installed with Python.

Note :
1. API key is generated when user signs in to the website Open Weather (https://openweathermap.org/).
2. Weather icons and other URLs can be fetched from the same website.
3. To install Pillow library, type 'pip install pillow' in the command prompt.
